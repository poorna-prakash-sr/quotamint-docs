---
title: "Run QuotaMint locally"
description: "Start the dashboard, runtime API, worker, and PostgreSQL for development"
---

A local QuotaMint environment runs the Next.js control plane and Go runtime against the same PostgreSQL database.

## Prerequisites

- Node.js and pnpm
- Go 1.24 or newer
- Docker with Compose
- PostgreSQL 17 if you are not using the provided Compose service

## Start the dashboard database

From the QuotaMint repository root:

```bash
pnpm install
cp .env.example .env.local
pnpm db:up
pnpm db:migrate
pnpm db:seed   # optional development fixture
```

Set the required values in `.env.local`:

| Variable | Purpose |
| --- | --- |
| `AUTH_SECRET` | Session signing secret |
| `AUTH_URL` | Public dashboard origin |
| `DATABASE_URL` | Shared PostgreSQL connection string |
| `QUOTAMINT_RUNTIME_INTERNAL_URL` | Server-only runtime URL |
| `QUOTAMINT_INTERNAL_API_KEY` | Must match the runtime's internal secret |
| `QUOTAMINT_RUNTIME_API_URL` | Runtime URL shown in developer examples |

Password sign-in works with `AUTH_SECRET`. Google and GitHub sign-in become available when their matching credential pairs are configured.

## Start the runtime

In a second shell:

```bash
cd services/runtime-api
cp .env.example .env
# Set DATABASE_URL and INTERNAL_API_SECRET in .env
go run ./cmd/api
go run ./cmd/worker
```

The API listens on `http://127.0.0.1:8080` by default. Run `go run ./cmd/worker -once` when you need to execute the worker jobs once for a local check.

Or start the runtime containers from the repository root:

```bash
docker compose --profile runtime up -d
```

## Verify the services

```bash
curl -sS http://127.0.0.1:8080/health
curl -sS http://127.0.0.1:8080/ready
curl -sS http://127.0.0.1:8080/metrics
```

`/health` checks only the process. `/ready` checks PostgreSQL.

## Run tests

Dashboard tests:

```bash
pnpm test
pnpm typecheck
pnpm lint
pnpm build
```

Runtime tests:

```bash
cd services/runtime-api
go test ./...
go test -race ./...
```

Set `TEST_DATABASE_URL` for the runtime PostgreSQL integration suite. Keep test databases separate from development data.
